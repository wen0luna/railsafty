# 自动演示（自动演练）流程说明

自动演示用于展台讲解和流程走查：它串联三维场景、异常告警、融合重建和仿真处置，让观众无需逐项操作即可看到一轮完整演练。所有状态变化都发生在本地演示界面中，不会发送真实调度或控制指令。

## 一轮演示概览

```text
全域总览（5 秒）
  → 列车巡航（7 秒）
  → 人员入侵 → 动物入侵 → 强降雨 → 边坡位移 → 落石侵限
      每类异常：异常特写（4.5 秒）
        → 融合重建（4 秒）
        → 多源复核（1.8 秒）
        → 仿真派发（1.8 秒）
        → 复查归档（1.8 秒）
  → 完成页（3.5 秒）
```

完整流程共 28 个阶段，未暂停时约 85 秒。五类异常按上面的顺序依次展示；每类异常的五个子阶段合计约 13.9 秒。

| 阶段 | 自动演示的画面与状态变化 | 时长 |
| --- | --- | ---: |
| 全域总览 | 显示全域场景与总览视角，切回三维实景模式 | 5 秒 |
| 列车巡航 | 切换到列车跟随巡航视角 | 7 秒 |
| 异常特写 | 触发当前异常，创建待处置的仿真告警并聚焦现场 | 每类 4.5 秒 |
| 融合重建 | 切换到融合重建视图并聚焦目标 | 每类 4 秒 |
| 多源复核 | 将告警从“待复核”推进到“已复核” | 每类 1.8 秒 |
| 仿真派发 | 将告警推进到“处置中”，展示对应场景的处置方案 | 每类 1.8 秒 |
| 复查归档 | 模拟现场复查、完成告警归档，并返回正常场景 | 每类 1.8 秒 |
| 完成页 | 返回全域总览，显示本轮演示完成 | 3.5 秒 |

## 如何控制

在自动演示控制条中选择操作：

- **开始**：场景加载完成后即可开始。若仍有未完成的告警，系统会阻止启动，避免自动演示覆盖当前处置流程；请先完成或手动中止该演练。
- **暂停 / 继续**：暂停会保留当前阶段及剩余时间；继续后从该阶段接着播放。
- **循环播放**：启用后，本轮完成时会从全域总览重新开始。播放过程中也可以调整循环选项。
- **停止 / 手动接管**：按停止按钮会停止自动计时并保留当前场景和告警阶段，之后可手动继续处置。操作三维场景或其他业务控件时，演示会先停止，再执行该操作；切换场景仍会按原流程中止并归档当前演练。暂停、停止、循环设置、语言切换和全屏操作不会触发手动接管。

控制条会显示当前阶段、步骤进度和运行中的倒计时。停止后若留有未完成告警，再次启动前仍需先完成或手动中止该告警。

## 仿真与留痕

自动演示会调用与手动处置相同的告警状态流程，但自动生成的复核、派发和复查记录会明确标注为“自动演示模拟”，不会伪装成人工操作。每类异常完成后会归档其仿真告警，再进入下一类异常。若场景不可用或某个阶段无法执行，演示会停止、显示失败提示并保留当前状态，方便检查或手动接管。
